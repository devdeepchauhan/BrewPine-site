## About the Game

Project Mycelium is the first active BrewPine prototype. It started as a question: what if 2D platformer movement felt more like flowing water than jumping between platforms?

The working answer is a movement system where the player sticks gently to surfaces, rounds corners with momentum, and builds speed through slopes in unexpected ways.

## Development Status

This is an early prototype. The core movement mechanic exists and is being tested. There is no complete level, no final art, and no release date.
